Sobre o jogo Blocos Caindo

Blocos Caindo é um jogo de encaixar peças que descem pela tela. Você gira e move cada peça para formar linhas completas, que somem e dão pontos. Se a pilha chegar ao topo, o jogo termina.

Aqui o jogo fica mais rápido conforme você avança: a cada 10 linhas limpas sobe um nível. Você pode guardar uma peça para usar depois, ver as próximas e fazer combos limpando linhas em jogadas seguidas. O recorde fica salvo no navegador.

É grátis, roda no navegador e funciona no teclado ou no celular, com botões e gestos na tela. Serve para partidas curtas e para quem gosta de bater a própria marca.

Como jogar

  1. No computador, mova a peça com as setas para a esquerda e para a direita. A seta para cima gira e a seta para baixo desce mais rápido.
  2. Aperte Espaço para derrubar a peça de uma vez. Aperte C para guardar a peça e usar depois.
  3. Complete linhas horizontais sem buracos para limpá-las e ganhar pontos.
  4. No celular, use os botões na tela ou os gestos no campo de jogo.
  5. Aperte P para pausar. O jogo acaba quando as peças chegam ao topo.

Controles

Setas movem · ↑ gira · Espaço derruba · C guarda · no celular: botões e gestos

Dicas

  • Mantenha a pilha baixa e plana, evitando buracos fechados por cima.
  • Use Guardar para reservar a peça comprida para quando abrir um espaço fundo.
  • Limpar várias linhas de uma vez rende bem mais pontos do que limpar uma a uma.
  • Olhe as próximas peças e planeje onde cada uma vai antes de ela chegar.
  • Encadeie limpezas em jogadas seguidas para fazer combos.

Perguntas frequentes

Dá para jogar Blocos Caindo no celular?

Dá. Aparecem botões na tela e o campo aceita gestos. Funciona direto no navegador.

O recorde fica salvo?

Fica. O melhor placar é guardado no navegador do aparelho em que você jogou.

Como funciona a pontuação?

Limpar linhas dá pontos, e limpar mais linhas de uma vez dá mais. Descer a peça mais rápido também soma pontos, e os combos rendem um bônus extra.
