Sobre o jogo 2048

2048 é um quebra-cabeça de números em um tabuleiro de 4 por 4. Você desliza todas as peças para uma direção. Quando duas peças com o mesmo número se encontram, elas se juntam em uma só com o valor somado. O objetivo é formar a peça 2048.

A cada jogada surge uma peça nova, quase sempre um 2 e às vezes um 4. A partida acaba quando o tabuleiro enche e não sobra nenhum movimento. Ao chegar ao 2048 você pode continuar jogando para fazer ainda mais pontos.

Esta versão guarda seu recorde e também a partida em andamento, então você pode fechar a página e voltar depois. Tem um botão de desfazer para a última jogada. É grátis e funciona no computador e no celular.

Como jogar

  1. No computador, use as setas ou W, A, S, D para deslizar todas as peças para cima, direita, baixo ou esquerda.
  2. No celular, deslize o dedo sobre o tabuleiro na direção desejada.
  3. Quando duas peças com o mesmo número se encostam, elas se juntam e a pontuação aumenta pelo valor da nova peça.
  4. Se errar, aperte Z ou o botão Desfazer para voltar uma jogada. Só a última jogada pode ser desfeita.
  5. Chegue à peça 2048 para vencer, ou continue jogando para aumentar a pontuação. Use Novo jogo para recomeçar.

Controles

Setas ou WASD · deslize no celular

Dicas

  • Escolha um canto para guardar a peça maior e evite mover na direção oposta sempre que puder.
  • Mantenha as peças grandes em fila, da maior para a menor, ao longo de uma borda.
  • Use poucas direções. Alternar entre duas ou três direções mantém o tabuleiro mais organizado.
  • Antes de cada jogada, olhe se há duas peças iguais que possam se juntar de uma vez.
  • Use o Desfazer com cuidado: ele só volta uma jogada, então pense antes de mover quando o tabuleiro estiver cheio.

Perguntas frequentes

Qual é o objetivo do 2048?

Juntar peças com o mesmo número até formar a peça 2048. O jogo avisa quando você chega lá e deixa você continuar, se quiser.

Dá para jogar 2048 no celular?

Dá. É só deslizar o dedo sobre o tabuleiro na direção em que quer mover as peças.

Posso desfazer uma jogada no 2048?

Pode. Aperte Z ou o botão Desfazer para voltar a última jogada. Não é possível voltar mais de uma.
